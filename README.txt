BINANCE LIVE ANALYZER - Android project

WHAT IT DOES
- Reads public Binance Spot market data (no API key)
- Displays live candlesticks and 24-hour market stats
- Calculates basic EMA(9/21), RSI(14), and MACD trend readings
- Shows educational BULLISH / BEARISH / WAIT status

SAFETY
- This is an educational market-observation demo.
- It does NOT place orders or connect to an exchange account.
- Do not treat indicators as guaranteed predictions or financial advice.
- Never add exchange trading keys to this demo.

BUILD APK
1. Install Android Studio on a computer.
2. Open this extracted BinanceLiveAnalyzer folder in Android Studio.
3. Allow Gradle sync and install any requested Android SDK.
4. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location.

NOTES
- Internet is required.
- The chart library is loaded from a CDN, so first launch needs internet.
- Binance public endpoints may be unavailable in some regions/networks.
